# 界面原型（设计走查用）

零构建、零依赖，双击就能看。这是成员 A 在写 React 之前用来定界面的一版静态原型，**不是产品代码**，视觉与状态确认后结构会搬进 `client/src/pages`。

## 文件清单

```
client/design/
├── prototype.html          界面本体，所有结构与样式都在这一个文件里
├── assets/
│   ├── hero-campus.webp    开始页主视觉（校门 · 落日）43 KB
│   ├── ending-dusk.webp    结局页横幅（落日林荫道）58 KB
│   └── side-{1..5}-{l,r}.webp  两侧远景 5 套主题 × 左右，共 542 KB（单张 35~77 KB）
└── README.md
```

**分享给队友时要发整个 `design` 文件夹**（打包成 zip），不能只发 `prototype.html`——12 张图都是外部文件，单发 HTML 会掉图。

掉图不会白屏：12 张 AI 插画下面各压着一层手绘内联 SVG，`<img>` 加载失败会自动 `remove()`，露出下层矢量图，界面照常可看。代价是风格退回简版。

## 八个状态怎么翻

页面顶部那条虚线分隔的**走查条不属于产品界面**，只是用来切状态的工具：

| 按钮 | 对应快照 phase | 说明 |
| --- | --- | --- |
| 开始页 | 无存档 / 有存档 | 两个按钮示意两种开局，实际只出现一个 |
| ① 待生成事件 | `待生成事件` | 事件生成中的骨架屏 + 呼吸提示 |
| ② 待选择 | `待选择` | 事件卡 + 3 个选项 + 「前面几天」抽屉 |
| ③ 展示结果 | `展示结果` | 结果文案 + 精力/金钱增减 |
| ④ 待生成结局 | `待生成结局` | 属性已锁定，只重试结局 |
| ⑤ 已结束 | `已结束` | 结局四段 + 四维档位 |
| 错误·可重试 | — | `error.retryable = true` |
| 错误·不可重试 | — | 存档版本不支持，不给任何会写存档的按钮 |

右上角「设计标注」开关控制黄色虚线框，里面写给团队看的规则说明。关掉就是干净的视觉稿。

## 改哪里

全部集中在 `<style>` 顶部的 `:root` 块，改一个变量全站生效：

- `--sky-top` / `--sky-bottom`：背景渐变的上下色，决定整体插画感。
- `--brand` / `--brand-deep`：主按钮和选中态的校园蓝。
- `--energy` / `--money`：精力与金钱两个资源的专用色。
- `--grade-a` ~ `--grade-d`：结局四个档位色。
- `--font-diary`：日记标题用的衬线字体。Windows 上会落到中易宋体，只在大字号（24px+）下使用，正文仍是黑体族。
- `--radius` / `--shadow`：卡片圆角和投影。

12 张图都是 AI 生成的位图，**不能像 SVG 那样改颜色**。要换图就重新生成同名文件覆盖 `assets/` 下的 webp（主视觉保持 990×660 与 1040×440 左右，两侧小景保持 440px 宽，WebP 质量 78~80）。两侧小景的抠图/裁切脚本在仓库外的 `vibe_images/key_side.py`（`python key_side.py 源图.png 目标.webp`），换风格时改那里的 `LO/HI/MAX_W/QUALITY` 重跑即可。`prototype.html` 里 `.art-frame` 和 `.side` 下面那两层内联 SVG 是兜底图，也可以自己改 `fill` 调色。

## 动效清单

全部用 CSS 关键帧驱动。JS 只做三件事：把鼠标坐标写成 `--mx/--my` 两个自定义属性、切屏时改 `.scene` 的 `data-scene`、顺带给刚换上的那套主题补上图片 `src`（按需加载，见「两侧远景」），没有 `requestAnimationFrame` 逐帧动画。

- `cm-kenburns`：插画 42 秒一个来回的极缓推近，让画面不呆板。
- `cm-breathe`：落日暖光 9 秒呼吸一次。
- `cm-fall`：落叶，开始页 5 片、结局页 4 片，每片的横向位置/时长/延迟/颜色由 `<i>` 上的 CSS 变量控制。
- `cm-drift`：两侧远景 23/28 秒上下极缓漂移，位图和兜底 SVG 共用这一条。
- `cm-page`：日记纸页 15~22 秒漂移，保留各自原有倾角。
- `cm-scene-in`：切屏换背景时 1 秒淡入（靠 `display:none → block` 重新触发动画，不需要 JS 参与）。

系统开了「减少动态效果」（`prefers-reduced-motion: reduce`）时以上全部关闭，落叶直接不渲染。产品代码里要保留这条。

## 素材来源与合规

12 张插画全部由 AI 生成，每张右下角原本都有一枚「Qoder AI 生成」角标。

- 两张主视觉（开始页 / 结局页）角标**还在**：渲染尺寸下角标只有几个像素，肉眼基本看不见，但文件里在。
- 十张两侧远景在抠图时角标被一并去掉了（它们落在画面上，45% 透明度下仍能看出是灰字）。抠图脚本在仓库外的 `vibe_images/key_side.py`，改参数可重跑。

**这是比赛素材，是否允许去掉角标、是否需要在文档里声明 AI 生成，需要团队定**，别默认已经合规。

## 桌面端（≥768px）只有两处变大

- 开始页主视觉：对称溢出窄栏到 660×400，标题 40px，引导语放宽到 520px。
- 结局页横幅：加高到 488×240（比例从 2.7 收到 2.0，落日和人物不再太小）。
- **窄栏刻意保持 560px 不加宽。** 事件详情约 350 字中文，栏宽一到 680px 就会变成一行四十多字的长句，读起来很累。放大的是画，不是正文。

溢出用的是 `margin-left:50%` + `translateX(-50%)`，宽度上限锁在 `min(660px, 92vw)`，所以不会撑出横向滚动条。

## 两侧远景（仅 ≥900px）

窄屏本来就不空，所以这些在 900px 以下整组隐藏，不参与排版。

**共 5 套主题，切屏时随机换一套**，避免每一屏两侧都长一个样：

| `data-scene` | 左 | 右 |
| --- | --- | --- |
| 1 | 宿舍台阶，两个背书包的学生往上走 | 亮着灯的教学楼 + 门口倚着的自行车 |
| 2 | 梧桐林荫道 + 一张空长椅 | 银杏树下倚着车的后座书包 |
| 3 | 拱形门廊，台阶上睡着一只猫 | 摞起的书 + 摊开的日记 + 一杯热饮 |
| 4 | 看台与跑道，学生躺在栏杆边歇着 | 足球门 + 球 + 靠在门柱上的人 |
| 5 | 湖心亭与垂柳，小桥上坐着猫 | 石拱桥 + 桥头长椅 + 芦苇 |

- 每套主题左右各一张**AI 生成的透明水彩小景**（440px 宽、1.6 倍图），温和的校园生活细节走的就是这一版；下面仍压着上一轮的扁平内联 SVG 作兜底，位图 `onload` 后给容器加 `has-art`，`.scene .side.has-art svg{display:none}` 把矢量收起来，`onerror` 则直接 `this.remove()`，所以掉图只是退回简版、不会留白。
- **按需加载**：十张共 542 KB，一屏只用其中两张，所以 `<img>` 上写的是 `data-src`，`pickScene()` 换主题时才把当前这套的两张补成 `src`，首屏只拉当前这一套（实测 88~130 KB）。不能用 `loading="lazy"`——祖先 `display:none` 里的图片永远不会开始下载，等它变可见也不会补触发。
- 切换靠 `.scene` 上的 `data-scene` 属性配 CSS 选择器实现，每套主题一个 `<div class="th th-N">`，未选中的整组 `display:none`。漂浮纸页和鼠标视差容器在主题外面，所以五套共用，不会切着切着纸页跑没影。
- 随机取值会排除上一次的那一套，保证每次切屏都看得见变化。搬进 React 时等价做法：`phase` 变化时随机取 1~5，不要把上一次的值放进 state 长期记忆；图片 `src` 跟着当前 state 渲染即可，天然就是按需加载。
- **五张漂浮日记纸页**：三张挂在远景组上，两张单独飘在中等高度补中段留白。纸页的横线是 `repeating-linear-gradient` 画的，不是图片。
- 整组透明度 `.45`（纸页 `.4`），在 `.scene .side` 一条规则里，想更淡或更实改这一个数。水彩本身是浅底，`.45` 已经比较轻；要更浓先动这里，别去改图片。
- 动效两层：远景组 23/28 秒上下极缓漂移（`cm-drift`），纸页 15~22 秒漂移兼带原有倾角（`cm-page`）。鼠标视差靠 `pointermove` 往 `.scene` 上写 `--mx/--my`，左右两组各自的 `--depth` 一正一负，所以是反向错开的。
- `prefers-reduced-motion: reduce` 时视差、漂移、换主题时的淡入全关。

宽度写的是 `min(19vw, calc(50vw - 380px))`：`50vw - 280px` 就是 560 窄栏一侧的留白，再让出 **100px**。这 100px 不是装饰余量——纸页用 `right:-6% / -14%` 故意探出容器，鼠标视差最大还能再推 ±17px，之前只让 40px 时 901~1100px 这一段会压到正文上 21~31px。≥1440px 由 `19vw` 封顶，所以桌面观感不受这条 `calc` 影响。

## 已验证与未验证

已用真实浏览器在 390 / 768 / 1440 / 2000 四档实测 8 个状态，并程序化断言：无横向溢出（`scrollWidth > 视口宽` 全为 false）；主视觉在四档下都精确居中（1440 档左右各留 390px）；关掉设计标注后，除结局页外任何一屏的可见文字都不含「学业」「社交」，且「待选择」屏不出现任何带符号数字（「展示结果」屏只有精力 `−2`，「待生成结局」屏只有精力 `−3`）；12 张 webp 均正常加载，把 `src` 改成不存在的路径后 `<img>` 自动移除、下层 SVG 露出。

本轮同时修掉一个既有布局缺陷：结局页横幅原先用 `margin-bottom:-22px` 把「结局 · 9 月 14 日」拉进了图片里，重叠约 10px，现已改为横幅与正文之间留 22px。

矢量版 5 套背景那一轮实测（1440 档同源 iframe，逐套切换量测）：5 套全部正常渲染，每套 2 组 SVG；48 次切屏随机取样覆盖 1~5 全部主题、**连续重复 0 次**；淡入动画触发并在 1 秒后回到 `opacity:1`，同一时刻只有 1 套显示、其余 4 套 `display:none`。两侧远景与 560 窄栏的净空在 901 / 950 / 1024 / 1100 / 1280 / 1440 / 1920 七档、并把鼠标视差推到最坏值的前提下全为正数（最小 32px，最大 224px）。

换成 AI 水彩小景这一轮实测（同源 iframe 量布局 + headless Edge 出图看观感）：200 次切屏后十张 `data-src` 全部补齐、`complete && naturalWidth` 十/十、`has-art` 十/十、兜底 SVG 全部 `display:none`；把 `src` 换成不存在的路径后 `<img>` 自行移除且不会加上 `has-art`，手动去掉 `has-art` 时兜底 SVG 由 `none` 回到 `block`，掉图退路成立。按位图的新高度重测净空，在 901 / 1000 / 1100 / 1280 / 1440 / 1728 / 1920 七档 × 五套主题、左右各自推到视差最坏值的前提下仍全为正（左最小 36px、右最小 29px），`scrollWidth` 各档均不超过视口宽，900px 及以下整组隐藏。关掉设计标注后规则断言不变：「待选择」屏无「学业/社交」字样、无带符号数字，「展示结果」屏只有精力 `−2`。

同一轮还发现并修掉两处：① 901~1100px 之间两侧远景会压到正文 21~31px（原因见上一节，纸页探出 + 视差没被 40px 余量覆盖）；② 第 5 套的亭子和桥、第 4 套的旗杆在 45% 透明度下几乎看不见或悬空，已重画——这三处现在只影响兜底矢量图。

未验证：两侧远景的密度和透明度只由作者自己看过，需要队友确认是否过满或过淡；桌面端没做左图右文的双栏海报版式；深色模式、超长 AI 文案（>800 字）、精力或金钱为负时的 HUD 表现都还没测。
