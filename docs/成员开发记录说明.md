# 成员开发记录说明

为便于 4 人并行开发和接口联调，每位成员在 `docs/` 目录维护一份自己的开发记录。建议文件名如下：

- `成员-M-前端.md`
- `成员-wy-后端.md`
- `成员-你好-AI.md`
- `成员-落羽-集成.md`

个人文档保持简短，并持续更新以下内容：

1. 当前负责的任务与预期完成时间。
2. 已完成内容及对应文件。
3. 使用或提供的接口、数据结构和环境变量。
4. 需要其他成员确认或协助的事项。
5. 已确认的重要决定及变更原因。
6. 本地验证方式、结果和仍存在的问题。

涉及多人使用的接口或规则，最终结论同步回 `接口约定.md`、`游戏规则.md` 或 `开发规划.md`，不能只保留在个人记录中。API 密钥、账号信息等敏感数据不写入任何文档。
