# CampusMock

一个简易的、事件驱动的大学新生生活 AI 模拟器。玩家在网页中扮演一名大学新生，经历校园生活事件、做出选择，并体验不同选择带来的变化。

前端负责展示游戏状态与交互，后端调用国内大模型 API，生成事件详情、可选行动和行动结果。

> 当前处于仓库初始化与需求整理阶段，以下内容为开发规划，尚未实现。

## 项目目标

- 围绕大学新生的学习、社交、社团和日常生活，提供轻量的文字模拟体验。
- 以事件和选择推动游戏进程，让玩家的行动影响角色状态及后续经历。
- 使用 AI 丰富事件内容，同时通过明确的规则维持游戏状态的一致性。
- 优先完成可运行的最小版本，再逐步扩展内容与玩法。

## 核心玩法

一次游玩的基本流程：

1. **开始生活**：创建角色并初始化游戏时间、角色属性和背景信息。
2. **触发事件**：根据当前阶段、角色状态和近期经历生成校园事件。
3. **做出选择**：阅读事件详情，从若干可选行动中选择一项。
4. **查看结果**：由 AI 生成结果描述，后端校验并结算属性变化。
5. **继续推进**：保存本次经历、推进游戏时间，进入下一个事件。

例如，玩家可能在“准备课堂测验”“参加社团招新”和“与室友聚餐”之间做出选择，从而影响学业、人际关系、精力或生活费，并为后续事件提供背景。

## 首版范围

- **基础角色状态**：暂定包含学业、社交、精力和生活费，具体数值规则待实现时确定。
- **事件展示与选择**：展示当前事件、选项、结果和角色状态变化。
- **AI 内容生成**：生成符合大学新生背景的事件详情、选项及选择后的结果。
- **连续游戏进程**：保留当前角色状态及近期事件摘要，使后续事件能够衔接已有经历。
- **基础异常处理**：处理 API 超时、调用失败或返回格式异常，支持重试且避免重复结算。

首版暂不包含多人联机、复杂地图、实时行动系统及完整校园经济系统。

## 系统设计

### Web 前端

- 展示游戏时间、角色属性、当前事件和历史记录。
- 提供开始游戏、选择行动和继续推进等操作。
- 展示生成中的等待状态及调用失败后的重试入口。

### 后端服务

- 管理游戏状态、事件流程和行动结算。
- 根据角色状态、近期经历和生成约束构建提示词。
- 对接国内大模型 API，统一处理模型请求和响应。
- 校验 AI 返回内容的结构、选项合法性和数值范围，再更新游戏状态。
- 在服务端保管 API 密钥，不向浏览器暴露。

### AI 生成边界

- **输入上下文**：游戏阶段、角色状态、近期事件摘要及本次生成要求。
- **生成事件**：返回事件标题、详情和带唯一标识的选项。
- **生成结果**：根据已选行动返回结果描述和建议的属性变化。
- **结构化输出**：优先使用 JSON，便于后端校验和前端展示。
- **规则约束**：AI 负责内容生成，后端负责状态校验、属性边界和最终结算。
